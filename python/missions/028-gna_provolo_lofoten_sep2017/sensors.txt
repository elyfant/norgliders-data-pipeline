# Scope: navigation + attitude + the science payload (Sea-Bird SBE 41CP CTD,
# WET Labs ECO FLNTU, Aanderaa Optode 3835) + the engineering channels useful

# leak/vacuum). Deliberately NOT the full ~1300 declared sensors — the
# u_/f_/cc_ config constants and unused proglet flags are not timeseries data
# and make the decode ~25x slower. Expand this file if a channel is needed.
